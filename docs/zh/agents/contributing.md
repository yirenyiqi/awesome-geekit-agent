# 贡献你的 Agent 接入

Awesome Geekit Agent 收集通过 Geekit 接入编程助手、桌面 Agent 与开源客户端的教程，欢迎补充新工具、更新配置或反馈客户端兼容性问题。

项目仓库位于 [YRYQ · Awesome Geekit Agent](https://github.com/yirenyiqi/awesome-geekit-agent)。

## 提交教程

1. Fork 仓库，选择 `docs/zh` 与 `docs/en` 中对应工具的教程，或新增同名的中英文页面。
2. 写明客户端版本、平台、资料核对日期和官方安装入口。
3. 提供 Geekit BaseURL、协议、API Key 配置方式与模型 ID 填写方法。
4. 添加首次运行步骤、脱敏验证结果与常见问题。
5. 更新仓库中英文 README 的目录，然后提交 Pull Request。

完整约定见仓库中的[贡献指南](https://github.com/yirenyiqi/awesome-geekit-agent/blob/main/CONTRIBUTING.zh-CN.md)。

## 反馈问题

通过 [GitHub Issues](https://github.com/yirenyiqi/awesome-geekit-agent/issues)提供客户端名称与版本、操作系统、协议、HTTP 状态码和复现步骤。日志与截图中的密钥、个人信息和项目内容应先脱敏。

欢迎提交界面操作、CLI 配置与不同平台的更新。维护者会根据官方资料、复现步骤和验证记录核对教程。
