# Contribute an Agent integration

Awesome Geekit Agent collects guides for connecting coding assistants, desktop Agents, and open-source clients to Geekit. Contributions can add tools, update settings, or report client compatibility issues.

The project is hosted at [YRYQ · Awesome Geekit Agent](https://github.com/yirenyiqi/awesome-geekit-agent).

## Submit a guide

1. Fork the repository and update the matching guides in `docs/zh` and `docs/en`, or add paired pages with the same filename.
2. Include the client version, platform, source-check date, and official installation source.
3. Document the Geekit BaseURL, protocol, API key configuration, and model ID selection.
4. Add first-run steps, redacted verification results, and troubleshooting.
5. Update both README directories and submit a pull request.

See the repository's [contribution guidelines](https://github.com/yirenyiqi/awesome-geekit-agent/blob/main/CONTRIBUTING.md) for details.

## Report an issue

Use [GitHub Issues](https://github.com/yirenyiqi/awesome-geekit-agent/issues) and include the client name and version, operating system, protocol, HTTP status, and reproduction steps. Redact keys, personal information, and project content from logs and screenshots.

UI instructions, CLI configuration, and platform updates are welcome. Maintainers review guides against official sources, reproduction steps, and verification records.
